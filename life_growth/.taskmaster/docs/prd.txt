# Life Growth App - Product Requirements Document

## Overview
Life Growth is a comprehensive personal development and habit tracking application that helps users monitor their daily activities, build positive habits, and track their personal growth journey. The app combines local data storage with cloud synchronization to ensure data availability across devices and offline functionality.

## Core Features

### 1. Daily Task Tracking
- **Reading Activities**: Track book reading (pages, time) and documentation reading
- **Physical Activities**: Monitor stretching, meditation, and walking (steps, duration)
- **Learning**: Track technology learning sessions with sources and URLs
- **Habit Avoidance**: Monitor avoiding negative habits and sweets
- **Entertainment**: Log movie/series watching with timing
- **Work Productivity**: Track daily work completion
- **Notes**: Add personal notes for each day

### 2. User Authentication & Data Management
- Secure user authentication via Supabase
- Local SQLite database for offline functionality
- Cloud synchronization with Supabase backend
- Data persistence across app sessions

### 3. Background Synchronization System
- **Automatic Sync**: Periodic background synchronization every 15 minutes
- **Conflict Resolution**: Intelligent handling of data conflicts between local and remote
- **Offline Support**: Full functionality when offline with sync when connection restored
- **Notification System**: User notifications for sync status, conflicts, and errors
- **Manual Sync**: User-initiated immediate synchronization

### 4. Data Models & Storage
- **Daily Tasks**: Comprehensive daily activity tracking
- **Habits**: Custom habit definitions with frequency and tracking
- **Daily Check-ins**: Mood, energy, and stress level monitoring
- **Goals**: Personal goal setting with categories, priorities, and progress tracking
- **Journal Entries**: Personal reflection and journaling with mood and tags

### 5. User Interface
- **Home Screen**: Overview of today's tasks with completion status
- **Daily Check-in Screen**: Detailed form for logging daily activities
- **Authentication Screen**: Secure login/signup interface
- **Progress Tracking**: Visual indicators of task completion
- **Responsive Design**: Works across mobile and desktop platforms

## Technical Requirements

### Architecture
- **Frontend**: Flutter framework for cross-platform compatibility
- **Local Database**: SQLite with Drift ORM for local data storage
- **Backend**: Supabase for authentication, real-time database, and cloud storage
- **Background Processing**: WorkManager for scheduled background tasks
- **Notifications**: Flutter Local Notifications for user alerts

### Data Synchronization
- **Bidirectional Sync**: Local ↔ Cloud data synchronization
- **Conflict Resolution**: Last-write-wins with user notification for conflicts
- **Incremental Sync**: Only sync changed data to optimize performance
- **Retry Logic**: Automatic retry for failed sync operations
- **Network Awareness**: Sync only when network is available

### Security & Privacy
- **User Authentication**: Secure login with Supabase Auth
- **Data Encryption**: Encrypted data transmission
- **Local Data Protection**: Secure local storage
- **Privacy Controls**: User control over data sharing and sync
